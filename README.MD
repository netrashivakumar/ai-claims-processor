# AI Claims Processor (Sr. Full Stack AI Project)

## Project Overview
An AI-driven platform for insurance adjusters to summarize claims and detect risks using RAG (Retrieval-Augmented Generation).

## Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Python, FastAPI, LangChain
- **Data:** PostgreSQL (pgvector), Redis
- **DevOps:** Docker, GitHub Actions, AWS
